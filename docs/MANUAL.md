## 1. 画面構成

| 領域 | 内容 |
| :--- | :--- |
| 上部ツールバー | 新規・開く・保存・Undo/Redo・検索置換・ページ設定・PDF/HTML出力・ズーム |

## 2. ツールバー機能

| ボタン | 機能 |
| :--- | :--- |
| 🗋 新規 | 新規文書を作成（未保存の変更があれば確認ダイアログ） |
| 📂 開く... | Markdownファイルを選択して開く（`.md` / `.txt`） |
| 🕒 最近使ったファイル | 直近8件のファイル履歴から再オープン（`%APPDATA%\Typer\recent_files.txt` に永続化） |
| 💾 保存 | 上書き保存 |
| 別名保存... | 名前を付けて保存 |
| ↶ / ↷ | Undo / Redo |
| 🔍 検索・置換 | 検索・置換バーの開閉 |
| ⚙ ページ設定 | ページ設定バーの開閉 |
| 🗂 アウトライン | 見出しアウトラインパネルの開閉 |
| 📄 PDF出力... | PDFファイルとして出力 |
| 🌐 HTML出力... | 単一HTMLファイルとして出力 |
| Typstコード（チェックボックス） | 生成された内部Typstコードを下部サブパネルに表示（デバッグ・確認用） |
| 100% / ＋ / － | プレビュー表示倍率のリセット・拡大・縮小 |

## 4. ページ設定バー

YAMLフロントマターを手書きしなくても、GUIから文書全体の設定を変更できます（双方向同期）。

| 項目 | 選択肢 |
| :--- | :--- |
| 用紙向き | A4縦 / A4横 |
| フォント | ゴシック体 / 明朝体 |
| 余白 | 狭 15mm / 標準 20mm / 広 25mm |
| 文字サイズ | 9.5pt 〜 12pt |
| 行間 | スライダー（1.1 〜 2.2） |
| 配色（アクセントカラー） | 青 / 緑 / 赤 / 紫 / 橙 — 見出し罫線・表ヘッダー・リンク色等に反映 |

対応するフロントマター：

```yaml
---
paper: A4
orientation: portrait   # portrait (縦) / landscape (横)
margin: 20mm
font-size: 10.5pt
line-height: 1.5
font: gothic             # gothic (ゴシック) / mincho (明朝)
accent-color: "#1a73e8"
---
```

## 5. 見出しアウトラインパネル

左端に見出し（`#` 〜 `######`）の一覧をツリー表示します。クリックすると該当見出しへエディタのカーソルがジャンプします。フェンスコードブロック内の `#` は見出しとして拾いません。

## 7. クイック書式挿入バー

エディタ上部のバーから、選択範囲のラップ、またはカーソル位置への挿入ができます。

| ボタン | 内容 |
| :--- | :--- |
| B 太字 / I 斜体 | `**text**` / `*text*` |
| U 下線 | `[text]{underline}` |
| 🔴 赤文字 / 🔵 青文字 / 🟢 緑文字 / 🟠 橙文字 / 🟣 紫文字 | `[text]{色}` |
| HEXカラー入力欄 + 🎨 適用 | 任意のカラーコードで着色 |
| 📊 列幅付き表 | `{widths: ...}` 付きの表サンプルを挿入 |
| ➡ 右寄せ段落 | `{align: right}` の日付・署名向けサンプル |
| ↔ 中央タイトル | `{align: center, size: ...}` のタイトルサンプル |
| ↕ 行間指定 | `{line-height: ...}` |
| 🖼 画像... | ローカル画像ファイルを選択してカーソル位置に挿入（ドラッグ＆ドロップも可） |
| 📄 改ページ | `:::pagebreak` |
| ↕ 空白行 | `:::space 1em` |
| 🔲 囲み枠 | `{box}` + 引用のサンプル |
| 📋 テンプレート | 業務文書テンプレートの挿入（下記8章） |
| 🧩 Typstコード | ` ```typst ``` ` フェンスのひな形を挿入 |

## 8. 業務文書テンプレート

「📋 テンプレート」メニューから、以下4種類の定型フォーマットをカーソル位置に一括挿入できます。

| テンプレート | 内容 |
| :--- | :--- |
| 📝 議事録 | 会議概要表・議題・決定事項・宿題事項（ToDo）表 |
| 🚨 障害・インシデント報告書 | 概要・発生状況と対応経緯表・原因・再発防止策表 |
| 📨 稟議書 | 申請情報表・申請理由・内容詳細・承認欄表 |
| 📅 日報 | 業務内容・進捗成果・課題相談事項・明日の予定 |

## 9. 独自拡張Markdown構文 一覧

標準Markdown（見出し・段落・リスト・表・引用・コード・画像・太字・斜体・`~~取り消し線~~`）に加えて、以下を利用できます。

### 9.1 表の列幅指定

```markdown
{widths: 22%, 48%, 30%}
| 項目 | 内容 | 備考 |
| :--- | :--- | :--- |
```

### 9.2 表ヘッダー背景色

```markdown
{header-bg: #fdf0e6}
| A | B |
| :--- | :--- |
```

### 9.3 段落・見出しの配置と行間

```markdown
{align: right}
2026年10月16日

{align: center, size: 16pt}
**タイトル**

{line-height: 1.2, size: 9.5pt}
行間と文字サイズを詰めた段落。
```

### 9.4 ブロック単位の文字色

```markdown
{color: red}
## このセクションだけ見出し文字を赤くする
```

### 9.5 インライン文字装飾

| 記法 | 内容 |
| :--- | :--- |
| `[重要事項]{red}` / `{blue}` / `{green}` / `{orange}` / `{purple}` | 文字色 |
| `[カスタム]{color: red, size: 12pt}` | 色・サイズの複合指定 |
| `{color:red\|重要事項}` | 旧式のパイプ記法（表セル外推奨） |
| `[下線テキスト]{underline}` | 下線 |
| `~~取り消し線~~` | 取り消し線（標準Markdown） |

### 9.6 画像とサイズ指定

```markdown
![alt文](path/to/image.png)
![alt文](path/to/image.png){width: 50%}
```

対応形式：PNG / JPEG / GIF / SVG / WebP。指定しない場合は既定で80%幅表示。

### 9.7 任意改ページ

```markdown
:::pagebreak
```

### 9.8 明示的な空白

```markdown
:::space 1em
:::space        (値省略時は既定で1em)
```

### 9.9 囲み枠ボックス

```markdown
{box}
> 注意事項などをここに記載します。
```

通常の引用（左バー＋塗りつぶし）ではなく、全周を罫線で囲んだボックス表示になります。

### 9.10 上級者向け：生Typstコードの直接記述

```markdown
​```typst
#line(length: 50%, stroke: 1pt)
​```
```

PDF出力時はそのままTypstとして評価されます。HTML出力では評価できないため、注記付きでソースをそのまま表示します。

> 複数の属性行（`{widths: ...}` と `{header-bg: ...}` など）は、ブロック直前に並べて書くと自動的にマージされます。

## 10. ファイル操作・安全機能

- **未保存変更の保護**：未保存の変更（タイトルバー `*`）がある状態でウィンドウを閉じる／新規作成／別ファイルを開こうとすると、保存確認モーダルが表示されます。
- **自動保存**：編集を30秒以上放置すると、自動でバックアップファイルを書き出します。
  - 保存済みファイルの場合：同じフォルダに `{ファイル名}.autosave.md`
  - 未保存の新規文書の場合：`%APPDATA%\Typer\untitled_autosave.md`
- **ドラッグ＆ドロップ**：`.md` / `.txt` ファイルで読み込み、画像ファイルでカーソル位置への挿入。

## 11. 出力（PDF / HTML）

| 出力形式 | 特徴 |
| :--- | :--- |
| PDF（`Ctrl+P`） | 提出・印刷用。生Typstコードもそのまま評価される |
| 単一HTML | ページ境界に依存せずブラウザで連続閲覧可能。CSS・ローカル画像（Base64）を1ファイルに内包 |

出力成功後は、ステータスバーの **「📂 開く」** ボタンからOS既定のアプリケーションで直接確認できます。

## 12. 今はまだできないこと

検討はしたものの、実装規模とのバランスで見送っている機能です。必要になったら相談してください。

- セル単位の完全な背景塗り（`{bg:}` は現状テキスト範囲のみの着色）
- 表のセル結合（colspan / rowspan）
- 画像の個別配置（左寄せ／右寄せ、文字回り込み）
- 上付き文字・下付き文字
- ページ番号の書式カスタマイズ（現状 `"1 / 2"` 固定）
- ページ共通のヘッダー・フッター（社外秘表記など）
- PDF内への目次（TOC）自動生成
