## 1. 画面構成

| 領域 | 内容 |
| :--- | :--- |
| 上部ツールバー | 新規・開く・保存・Undo/Redo・検索置換・ページ設定・PDF/HTML/Word出力・ズーム・ダークモード切替 |
| ページ設定バー（開閉可） | 用紙向き・フォント・余白・文字サイズ・行間・アクセントカラーのGUI設定 |
| 見出しアウトラインパネル（開閉可、左端） | 見出し一覧とジャンプ |
| タブバー（中央ペイン上部） | 複数文書の切り替え・新規タブ（`Ctrl+T`）・タブを閉じる（`Ctrl+W`） |
| 中央（左ペイン） | マークアップエディタ本体（シンタックスハイライト付き） |
| 右ペイン | ページプレビュー（実際の組版結果を画像として表示） |
| 下部ステータスバー | ファイル名・カーソル位置・文字数/行数・ページ数・組版時間・通知メッセージ |

### 複数文書タブ

- **＋ボタン / `Ctrl+T`**：現在のタブの内容を保持したまま、空の新規文書を新しいタブとして開きます。
- **タブをクリック**：そのタブに切り替えます（未保存の状態を含め、タブごとに文書・Undo/Redo履歴・カーソル位置が独立して保持されます）。
- **× ボタン / `Ctrl+W`**：現在のタブを閉じます。未保存の変更がある場合は保存確認ダイアログが表示されます。最後の1枚を閉じようとした場合は、タブ自体は閉じずに空の新規文書にリセットされます。
- **「開く」（`Ctrl+O`）でのファイル読み込みは、新規タブではなく現在アクティブなタブの内容を置き換えます**。別タブで開きたい場合は、先に `Ctrl+T` で新規タブを作成してから「開く」を実行してください。
- **`.md` / `.txt` ファイルをウィンドウへドラッグ＆ドロップした場合は、「開く」とは異なり自動的に新規タブとして開かれます**（現在編集中のタブはそのまま保持されます）。
- **自動保存はアクティブなタブのみが対象**です。バックグラウンドのタブに未保存の変更がある状態で長時間放置しても、そのタブ自体の自動保存は行われません（ウィンドウを閉じる際の保存確認では、全タブの未保存状態がチェックされるため、データが気づかず失われることはありません）。

## 3. ショートカットキー

| :--- | :--- |

| `Ctrl + T` | 新規タブを開く（現在のタブの内容は保持） |
| `Ctrl + W` | 現在のタブを閉じる |
| `Ctrl + O` | ファイルを開く（現在のタブを置き換える） |

| `Ctrl + P` | PDF出力 |

| `Ctrl + B` / `Ctrl + I` / `Ctrl + U` | 選択範囲を太字 / 斜体 / 下線で囲む |

| ショートカット | 動作 |

## 4. ページ設定バー

YAMLフロントマターを手書きしなくても、GUIから文書全体の設定を変更できます（双方向同期）。

| 項目 | 選択肢 |
| :--- | :--- |
| 用紙向き | A4縦 / A4横 |
| フォント | ゴシック体 / 明朝体 / カスタム（任意のフォント名を入力。候補から選択可） |
| 欧文 | 英数字だけに使うフォント（空欄なら和文フォントのまま。候補から選択可） |
| 余白 | 狭 15mm / 標準 20mm / 広 25mm |
| 文字サイズ | 9.5pt 〜 12pt |
| 行間 | スライダー（1.1 〜 2.2） |
| 配色（アクセントカラー） | 青 / 緑 / 赤 / 紫 / 橙 — 見出し罫線・表ヘッダー・リンク色等に反映 |
| ページ番号（チェックボックス） | PDF出力時の各ページ下部のページ番号表示をON/OFF（既定: ON） |
| 段組み | 1段 / 2段 / 3段 — 本文を新聞風の段組みレイアウトに |
| 透かし（チェックボックス＋文字入力） | 本文背面に薄く表示する透かし文字（既定: 「社外秘」。任意の文字に変更可） |

対応するフロントマター：

```yaml
---
title: 月次業務報告書    # 省略可。HTMLのブラウザのタブ名・PDFの文書タイトル（省略時は最初の見出し → ファイル名）
paper: A4
orientation: portrait   # portrait (縦) / landscape (横)
margin: 20mm
font-size: 10.5pt
line-height: 1.5
font: gothic             # gothic (ゴシック) / mincho (明朝) / 任意のフォント名（例: "Meiryo UI", "Noto Sans JP"）
font-latin: Times New Roman  # 省略可。英数字だけに使う欧文フォント（和文は font のまま）
accent-color: "#1a73e8"
header: 社内限定資料      # 省略可。全ページ共通のヘッダー文字列（右寄せ）
footer: 社外秘            # 省略可。全ページ共通のフッター文字列（ページ番号と並記）
page-number: off         # 省略可。ページ番号を非表示にする場合のみ指定（off/false/no/none/0）
columns: 2               # 省略可。本文の段組み数（1〜4。既定: 1 = 段組みなし）
watermark: 社外秘         # 省略可。本文背面に薄く表示する透かし文字
会社名: 株式会社サンプル   # 省略可。上記以外のキーは独自変数になる（4.2参照）
---
```

### 4.1 フォントの指定

`font` に `gothic` / `mincho` 以外の文字列を指定すると、Windowsにインストール済みの任意のフォント名としてそのまま使用されます（ページ設定バーの「カスタム」ボタンからも入力可能）。指定したフォントがシステムに見つからない場合は、ゴシック体にフォールバックします。

「カスタム」入力欄にフォーカスすると、読み込み済みのフォント名を入力中の文字で絞り込んだ候補一覧がポップアップ表示されます。候補をクリックすれば正式なフォント名を手打ちせずに選択できます。

候補には、ひらがな・カタカナ・常用漢字（「報」「文」で判定）をすべて含むフォントのみを表示します。Windowsには英数字専用フォント（Arial, Consolas等）や記号専用フォント、ひらがなだけでは漢字グリフを持たない装飾フォントも多数入っていますが、これらを指定しても本文の漢字部分はTypstの自動フォールバックでゴシック体のまま描画され「選んでも見た目が変わらない」ように見えてしまうため、候補からは除外しています。英数字専用フォント等をどうしても使いたい場合は、入力欄に直接フォント名を手入力すれば（候補に出なくても）指定は可能です。

ページ設定バーの「欧文:」欄（フロントマターの `font-latin`）に指定したフォントは、英数字だけに使われます。和文は `font` のフォントのまま残るため、「和文は游明朝、欧文はTimes New Roman」のような組み合わせができます。日本語グリフも持つフォント（HackGen等）を欧文欄に指定しても、和文側には影響しません。空欄なら和文フォントの英数字をそのまま使います。Word出力では欧文フォントを「英数字用フォント」、和文フォントを「日本語用フォント」として設定します。

候補にはWindowsのフォントフォルダに加えて、ユーザー単位でインストールしたフォント（`%LOCALAPPDATA%\Microsoft\Windows\Fonts`）も表示されます。起動直後の約1秒間は定番フォントのみで、全フォントの読み込みが終わると自動的に追加されます。

なお、候補として表示されるフォント同士でも、書体の作り（字形デザイン）が近いゴシック体どうし（例: BIZ UDGothicとYu Gothic）を切り替えると、文字サイズが小さい箇所では違いが分かりにくいことがあります。これはフォントが正しく適用された上での見た目の近さであり、不具合ではありません。

### 4.2 独自変数（`{{キー}}` の差し込み）

フロントマターに上記以外のキーを書くと独自変数になり、本文中の `{{キー}}` がその値に置き換わります。社名・担当者名・案件名など、文書内で何度も出てくる語句を1か所で管理できます。

```markdown
---
会社名: 株式会社サンプル
担当: 山田
header: {{会社名}} 社内資料
---

# {{会社名}} 月次報告書

担当: {{担当}}
```

- 本文のほか、`title` / `header` / `footer` / `watermark` の中でも使えます。
- 定義されていないキーの `{{キー}}` は、そのまま文字として残ります。
- コードブロック（` ``` `）の中は置き換えません。
- ページ設定バーを操作しても、フロントマターの `{{会社名}}` は値で上書きされず、そのまま残ります。

### 4.3 ヘッダー・フッター・段組みの補足

> `columns` はフロントマターで指定すると文書全体が段組みになります。文中の一部分だけを段組みにしたい場合は、範囲指定の `:::columns 2` 〜 `:::columns-end` を使用してください（段数は2〜4、省略時は2段）。

```markdown
:::columns 2
ここからここまでの範囲だけが2段組みで表示されます。見出し・表・リストなども範囲内に含められます。
:::columns-end
```

> `page-number: off` と `footer` を同時に指定した場合、フッターにはページ番号を含めずフッター文字列のみが中央に表示されます。

> `header` / `footer` はページ設定バーにGUI項目がないため、フロントマターに直接記述してください。PDF出力では各ページに繰り返し表示され、`footer` を指定した場合も既存のページ番号表示（「N / 総ページ数」）は失われず、フッター文字列と並べて表示されます。HTML出力ではページという概念がないため、文書の先頭・末尾に1回だけ表示されます。

## 5. 見出しアウトラインパネル

左端に見出し（`#` 〜 `######`）の一覧をツリー表示します。クリックすると該当見出しへエディタのカーソルがジャンプします。フェンスコードブロック内の `#` は見出しとして拾いません。

## 9. 独自拡張Markdown構文 一覧

標準Markdown（見出し・段落・リスト・表・引用・コード・画像・太字・斜体・`~~取り消し線~~`）に加えて、以下を利用できます。

> 番号付きリストは `5. 項目` のように1以外の数字から書き始めると、PDF/HTML出力どちらもその番号から開始されます。

### 9.1 表の列幅指定

```markdown
{widths: 22%, 48%, 30%}
| 項目 | 内容 | 備考 |
| :--- | :--- | :--- |
```

### 9.2 表ヘッダー背景色

```markdown
{header-bg: #fdf0e6}
| A | B |
| :--- | :--- |
```

### 9.2.1 表のセル内上下余白（行の高さ）

```markdown
{row-padding: 14pt}
| 項目 | 内容 |
| :--- | :--- |
| 例 | この表だけ行の余白を広めに |
```

Excelのような「中身が空でも固定の行高さ」は組版の仕様上表現できませんが、セル内の上下余白（既定はPDF/HTMLで6pt相当、Wordで4pt）を広げることで、行全体にゆとりを持たせられます。PDF/HTML/DOCXの全出力形式に反映されます。

### 9.3 段落・見出しの配置と行間

```markdown
{align: right}
2026年10月16日

{align: center, size: 16pt}
**タイトル**

{line-height: 1.2, size: 9.5pt}
行間と文字サイズを詰めた段落。
```

### 9.4 ブロック単位の文字色

```markdown
{color: red}
## このセクションだけ見出し文字を赤くする
```

### 9.5 ブロック単位の表示幅

HTML/CSSの`width`に相当する指定です。見出し・段落・引用などを、表以外の任意のブロックで幅制限できます。`align`と組み合わせて中央寄せ・右寄せが可能です（`align`省略時は左寄せ）。

```markdown
{align: center, block-width: 60%}
この段落だけ幅60%で中央に表示されます。
```

> 表の列幅指定（`{widths: ...}` / `{width: ...}`）とは別のキーです。表以外のブロックで使う場合は必ず `block-width` を使ってください。

### 9.6 段落のインデント（段下げ）

段落・見出し・引用などを左右に一定量シフトして表示します。値は長さ（`mm`, `pt`, `em`など）で指定します。

```markdown
{indent: 20mm}
この段落は左側に20mm分インデントされます。
```

左右で異なる量を指定したい場合は `indent-left` / `indent-right` を使います。

```markdown
{indent-left: 10mm, indent-right: 5mm}
左右で異なる量だけインデントされた段落です。
```

`block-width`や`align`と組み合わせることもできます。

### 9.7 インライン文字装飾

| 記法 | 内容 |
| :--- | :--- |
| `[重要事項]{red}` / `{blue}` / `{green}` / `{orange}` / `{purple}` | 文字色 |
| `[カスタム]{color: red, size: 12pt}` | 色・サイズの複合指定 |
| `{color:red\|重要事項}` | 旧式のパイプ記法（表セル外推奨） |
| `[下線テキスト]{underline}` | 下線 |
| `~~取り消し線~~` | 取り消し線（標準Markdown） |
| `[背景付き文字]{bg: #fff2cc}` | 文字の背景をハイライト（マーカー風）する |

> 表のセル内で、セルの中身**全体**を `[...]{bg: ...}` で囲むと、マーカー風のハイライトではなく、そのセル自体を完全に塗りつぶす表示になります（PDF/HTML両方対応）。
> ```markdown
> | 項目 | 状態 |
> | :--- | :--- |
> | 対応済み | [完了]{bg: #e6f4ea} |
> ```

### 9.8 画像とサイズ指定・浮動配置

```markdown
![alt文](path/to/image.png)
![alt文](path/to/image.png){width: 50%}
![alt文](path/to/image.png){width: 30%, float: true, dx: 10mm, dy: -5mm}
```

対応形式：PNG / JPEG / GIF / SVG / WebP。指定しない場合は既定で80%幅表示。

`float: true` を指定すると、画像を本文の流れから外し、現在のカーソル位置を基準に重ねて表示します（透過PNGなどを文章の上に配置する用途向け）。通常の画像は配置された分だけ後続の文章が押し下げられますが、`float`指定時は後続の文章に影響しません。`dx`（水平方向）・`dy`（垂直方向）でオフセットを微調整できます（省略時は0mm、プラス値で右・下方向）。PDF/HTML出力に対応。DOCX出力では非対応のため、通常の画像と同様に `[画像: alt文]` というテキスト表記に置き換わります。

```markdown
:::pagebreak
```

### 9.10 明示的な空白

```markdown
:::space 1em
:::space        (値省略時は既定で1em)
```

### 9.11 囲み枠ボックス

```markdown
{box}
> 注意事項などをここに記載します。
```

通常の引用（左バー＋塗りつぶし）ではなく、全周を罫線で囲んだボックス表示になります。

### 9.12 段落内の改行・表セル内の改行

段落を分けずにその場所だけで改行したい場合は、行末に **バックスラッシュ `\`** を置きます。

```markdown
1行目の文章です\
2行目として改行されて表示されます
```

ただし、表のセルは1物理行でしか書けないため、上記の方法は使えません。その場合はセル内に **`<br>`**（`<br/>` / `<br />` も可、大文字小文字も区別しません）を直接記述してください。`Shift+Enter` でカーソル位置に挿入することもできます。

```markdown
| 項目 | 説明 |
| :--- | :--- |
| 1行目<br>2行目 | 備考 |
```

### 9.13 上級者向け：生Typstコードの直接記述

```markdown
​```typst
#line(length: 50%, stroke: 1pt)
​```
```

PDF出力時はそのままTypstとして評価されます。HTML出力では評価できないため、注記付きでソースをそのまま表示します。

数式記法（`$alpha + beta = gamma$` のようなTypstの数式構文）も、このフェンス内でそのまま利用できます。通常は本文に `$...$` でLaTeX記法の数式を書く方が手軽です（[9.15](#915-数式--)参照）。フェンス内のTypst数式は、9.15の変換で対応していない記法（行列など）を使いたい場合の手段です。

> 複数の属性行（`{widths: ...}` と `{header-bg: ...}` など）は、ブロック直前に並べて書くと自動的にマージされます。

### 9.14 目次（TOC）の自動挿入

```markdown
:::toc
```

挿入した位置に、文書内の見出し（`#` 〜 `######`）から自動生成された目次が入ります。見出しを追加・削除・変更しても目次側を手直しする必要はありません。

- **PDF出力**：Typst標準の `#outline()` 機能を使用するため、各項目にページ番号が自動で付きます。
- **HTML出力**：見出しへのアンカーリンク一覧（入れ子表示）として出力され、クリックで該当見出しへジャンプできます。
- 見出しが1つもない文書では、目次欄は出力されません（空の枠は表示されません）。

### 9.15 数式（`$...$` / `$$...$$`）

```markdown
1. $4 \times 6 + 18 =$
2. $\frac{1}{2} + \frac{1}{3} = \frac{5}{6}$

$$
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}
$$
```

`$...$` は文中の数式、行を分けて書いた `$$...$$` は中央寄せの独立した数式になります。中身はLaTeX記法で書きます。

- **対応している主な記法**：四則演算（`\times` `\div` `\pm` `\cdot`）、分数（`\frac{a}{b}`）、平方根（`\sqrt{x}` `\sqrt[3]{x}`）、べき乗・添字（`x^2` `a_{n+1}`）、関係演算子（`\le` `\ge` `\neq` `\approx`）、ギリシャ文字（`\alpha` `\pi` `\Omega` 等）、総和・積分（`\sum` `\int`）、矢印、集合記号、`\text{...}`（数式中の普通の文字）、`\left( \right)` など。
- 対応していないコマンドは、`\foo` のように文字のまま表示されます（文書全体が表示されなくなることはありません）。
- **金額表記との区別**：`$100 と $200` のように、開き `$` の直後や閉じ `$` の直前に空白がある場合や、閉じ `$` の直後が数字の場合は数式として扱いません。
- 見出し・箇条書き・表のセル・太字・色付け（`[...]{red}`）の中でも使えます。
- 行列・場合分け（`\begin{pmatrix}` `\begin{cases}` など `\begin{...}` 系）、`\mathbb` `\mathcal` `\color` には未対応です。行列などが必要な場合は ` ```typst ` フェンス内でTypstの数式構文を使ってください（[9.13](#913-上級者向け生typstコードの直接記述)）。
- **HTML・Word出力**：PDFと同じTypstで数式を組み、HTMLではSVG画像、WordではPNG画像として埋め込みます。見た目はPDFと同じで、文中の数式は本文の文字の高さに揃います。HTMLは外部ファイルやJavaScriptなしで1ファイルのまま開けます。
  - 画像なので、数式部分の文字を選択・コピーすることはできません（画像の代替テキストに元の記法 `$...$` が入っています）。
  - Word出力の数式は、Word上で数式として編集することはできません。
  - 万一組版できない数式があった場合は、その数式だけ元の記法のまま等幅で出力されます。

## 10. ファイル操作・安全機能

- **未保存変更の保護**：未保存の変更（タイトルバー `*`）がある状態でウィンドウを閉じる／新規作成／別ファイルを開こうとすると、保存確認モーダルが表示されます。複数タブを開いている場合、ウィンドウを閉じる際はバックグラウンドの他タブの未保存状態も含めてチェックされます。
- **自動保存**：編集を30秒以上放置すると、自動でバックアップファイルを書き出します（アクティブなタブのみが対象。[複数文書タブ](#複数文書タブ)参照）。
  - 保存済みファイルの場合：同じフォルダに `{ファイル名}.autosave.md`
  - 未保存の新規文書の場合：`%APPDATA%\Typer\untitled_autosave.md`
- **ドラッグ＆ドロップ**：`.md` / `.txt` ファイルは新規タブとして読み込み（[複数文書タブ](#複数文書タブ)参照）、画像ファイルはカーソル位置への挿入。

## 11. 出力（PDF / HTML / Word）

| 出力形式 | 特徴 |
| :--- | :--- |
| PDF（`Ctrl+P`） | 提出・印刷用。生Typstコードもそのまま評価される |
| 単一HTML（`Ctrl+Shift+E`） | ページ境界に依存せずブラウザで連続閲覧可能。CSS・ローカル画像（Base64）・数式（SVG画像）を1ファイルに内包 |
| Word（.docx）（「📝 Word出力...」） | Microsoft Word形式。見出し・段落・表・リスト・改ページ・目次（フィールドコード）・ローカル画像・和文/欧文フォント指定等に対応 |

出力成功後は、ステータスバーの **「📂 開く」** ボタンからOS既定のアプリケーションで直接確認できます。

HTMLのブラウザのタブ名とPDFの文書タイトル（PDFビューアーのタイトルバーやプロパティに表示される名前）は、フロントマターの `title`、なければ文書の最初の見出し、それもなければ保存しているファイル名になります。新規文書やページ設定バーで書き戻したフロントマターには、空の `title:` 行が入ります。空のままなら最初の見出しが使われるので、別の名前にしたいときだけ書き足してください。

### Word（.docx）出力の制限事項

Word出力は独自の軽量OOXML生成器によるもので、PDF/HTML出力ほど高機能ではありません。以下にご留意ください。

- **画像はPNG / JPEG / GIFのみ埋め込まれます**：SVG / WebP画像と、`float: true` を指定した浮動配置の画像は `[画像: alt]` というテキスト表記に置き換わります。
- **数式は画像で埋め込まれます**：PDFと同じ見た目のPNG画像として入るため、Word上で数式として編集することはできません。
- **表のセルには上下4ptの余白が付きます**（`{row-padding: ...}` を指定した場合はその値）。
- **リンクは実クリック不可**：`[テキスト](url)` は青文字・下線の装飾のみ再現され、実際にジャンプするハイパーリンクにはなりません。
- **目次（`:::toc`）はWordのフィールドコードとして出力**：ファイルを開いた直後は仮のプレースホルダ文言が表示されるため、目次上で右クリック→「フィールド更新」（または対象を選択して`F9`キー）を実行してください。
- **`{bg: ...}` の背景色（文字ハイライト・セル全体塗り）は反映されません**（表のヘッダー背景色 `{header-bg: ...}` は反映されます）。
- **` ```typst ` フェンスの生Typstコードは評価されず**、注記のみ出力されます（PDF専用機能のため）。

### 組版エラー時の行番号表示

` ```typst ` フェンスの記述ミスなどで組版エラーが発生すると、右ペイン上部に表示されるエラーメッセージに **`[生成コード N行目]`** という形で行番号が付きます。この行番号は、ツールバーの「Typstコード」チェックボックスで表示できる生成済みTypstコード側の行番号です（編集中のMarkdown原稿そのものの行番号とは対応しないため、該当のTypstブロックやその前後を手がかりに原稿側を確認してください）。

## 12. 今はまだできないこと

検討はしたものの、実装規模とのバランスで見送っている機能です。必要になったら相談してください。

- 表のセル結合（colspan / rowspan）
- 画像の個別配置（左寄せ／右寄せ、文字回り込み）
- 地の文での上付き文字・下付き文字（数式の中なら `$x^2$` `$H_2O$` のように書けます）
- 数式の行列・場合分け（` ```typst ` フェンス内のTypst数式なら可能）
- Word出力での編集可能な数式（現在は画像として埋め込み）
- ページ番号の書式カスタマイズ（ON/OFF切り替えは可能。「N / 総ページ数」以外の書式への変更は現状非対応）

### 既知の制限：絵文字の表示について

- **エディタ画面（ツールバーのアイコン等）**：Windows用の絵文字フォント（Segoe UI Emoji）はカラーグリフ形式のため、アプリの描画ライブラリ（egui/epaint）が対応しておらず、一部のアイコンが四角（☒）で表示されます。アプリの不具合ではなく、使用しているUIライブラリの既知の制限です。
- **本文中に絵文字を書いた場合（プレビュー・PDF出力）**：Typstの組版フォントにSegoe UI Emojiを追加済みのため、主要な絵文字（📖 🕒 📂 等）はカラー／モノクロで表示されますが、一部の絵文字（🗋 等）は非対応のまま四角になります。業務報告書の本文で絵文字を多用する想定は薄いため、現状は実用上の優先度を下げています。
