# Word出力の確認手順（ロードマップ 6-4 / 13-14）

Word（.docx）出力は自前で組み立てているため、Microsoft Wordの実機で開いて確かめる必要があります。このフォルダの [sample.md](sample.md) は、Word出力で使える機能をひと通り含んだ確認用の原稿です。

## 手順

1. Typerで `sample.md` を開く（画像を読み込むため、このフォルダに置いたまま開く）
2. 「📝 Word出力...」で `.docx` に書き出す
3. Microsoft Wordで開き、下の確認項目を順に見る
4. 目次の上で右クリック →「フィールド更新」（または `F9`）を実行してから、目次の項目を確認する

## 確認項目

### 開いたとき

- [ ] 「読み取れない内容が含まれています」「修復しますか」などのダイアログが出ない
- [ ] 用紙がA4縦、余白が上下左右20mm（レイアウト → 余白 → ユーザー設定の余白 で確認）

### フォント

- [ ] 本文の和文が明朝体（游明朝）、英数字が Times New Roman になっている（文字を選択してフォント欄を確認）
- [ ] コードブロックとインラインコードの英数字が Consolas

### 文字の装飾（1章）

- [ ] 太字・斜体・取り消し線・下線・赤文字・14ptの文字がPDFと同じように見える
- [ ] 「背景色付き」の背景が薄い黄色、「全部まとめて」の背景が薄い青
- [ ] 「Typstの公式サイト」「メール」「こちら（脚注内）」が `Ctrl`+クリックで開けるリンクになっている
- [ ] 「表の章へ」は青・下線の文字だけで、リンクにはなっていない（仕様）
- [ ] 日付・部署名が右寄せ、タイトルが中央寄せで16pt、字下げ段落が左に20mm下がる

### リスト（2章）

- [ ] 箇条書きの記号が「•」「◦」「▪」と深さごとに変わる
- [ ] 番号付きリストが「3.」「4.」から始まり、入れ子が「1.」「2.」から振り直される
- [ ] 箇条書きの項目でTabキー・Shift+Tabを押すとレベルが変わる（Word本来の箇条書きであること）
- [ ] チェックリストが ☐ / ☑ で表示され、行頭記号が付かない

### 表（3章）

- [ ] 列幅がおおよそ 25% : 45% : 30%
- [ ] 見出し行の背景が薄いオレンジ、見出しの文字が太字
- [ ] 「備考」列が中央寄せ
- [ ] 「セル内の」「改行」が2行に分かれている
- [ ] 「セル全体を塗る」のセルが、文字の背景ではなくセル全体が薄い黄色で塗られている
- [ ] 数式の画像がセルの罫線に接していない

### 引用・コード・脚注（4章）

- [ ] 引用が左に字下げされ、入れ子の引用はさらに深く字下げされる
- [ ] コードブロックの字下げ（行頭の空白）が保たれている
- [ ] 脚注がページ下部に「1」として入り、2回目の参照も同じ「1」を指す

### 数式と画像（5章）

- [ ] 文中の数式（$x^2+y^2=r^2$）の高さが前後の文字とおおむね揃っている
- [ ] 独立した数式（2次方程式の解の公式）が中央に表示される
- [ ] アイコン画像が本文幅の約30%で表示され、縦横比が崩れていない

### ページ・目次

- [ ] 各ページの右上に「株式会社サンプル 確認用」（ヘッダー）が灰色の小さな文字で出る
- [ ] 各ページの下に、左「社外秘」・右「1 / 3」のようなフッターが出る（ページ番号は Wordが計算する）
- [ ] 見出しがページの最下部に取り残されず、次の段落と同じページに入る
- [ ] 「6. 改ページ後のページ」が新しいページから始まる
- [ ] 6章の「株式会社サンプル」が差し込まれている
- [ ] フィールド更新後の目次に1〜6章の見出しが並ぶ

## 既知の違い（PDFと同じにならないもの）

[docs/MANUAL.md](../MANUAL.md) の「Word（.docx）出力の制限事項」を参照してください。透かし（`watermark`）・段落の行間（`line-height`）と幅（`block-width`）は出力されません。

## 開発者向け：原稿を3形式まとめて書き出す

アプリを使わずに、この原稿をWord・PDF・HTMLへまとめて書き出せます（PowerShell）。

```powershell
$env:TYPER_EXPORT_DIR = "$env:TEMP\typer-word-check"; cargo test word_check_export -- --ignored
```
