# Typer

**Markdownの気軽さで文章を書き、必要な書式だけを指定して、読みやすいPDF報告書を簡単に作成できる軽量デスクトップアプリケーション**

Microsoft Wordのような高機能ワープロの完全な代替ではなく、**テキストを中心とした簡潔な操作で、体裁の整った社内報告書・業務文書・議事録・手順書を効率よく作成すること**を目指しています。

> 📖 全機能を棚卸しした操作マニュアルは [docs/MANUAL.md](docs/MANUAL.md) を参照してください。

---

## 主な特徴

- **Markdownベースの書き味＋業務文書向け拡張構文**
  - 基本は標準Markdown（見出し・段落・リスト・表・引用・コード・画像）のまま記述可能
  - 標準Markdownでは手が届かない **「表の列幅指定」「段落の行間・右寄せ/中央寄せ」「部分的な文字色・文字サイズ変更」「任意改ページ」「A4用紙・余白設定」** をシンプルな構文で制御可能
- **Typst組版エンジン内蔵による高品質な日本語PDF出力**
  - 外部ツールのインストール不要（RustクレートとしてTypstを直接内蔵）
  - 日本語の文字折り返し・禁則処理、見出し直後の不自然な改ページ抑制（`sticky`）、表ヘッダデザイン・セル内折り返しに対応
  - Windows標準の日本語フォントをプロセス起動時に一度だけ共有キャッシュ（`OnceLock`）し、プレビュー更新もPDF出力も数十ミリ秒で高速完了
- **実用的なエディタ機能・操作性（`egui` 2ペインUI）**
  - **カーソル位置への書式挿入・選択テキストのラップ挿入**：テキストを選択して「🔴 赤文字」や `Ctrl+B`（太字）・`Ctrl+I`（斜体）を押すと選択範囲をそのまま装飾
  - **GUI文書設定バー**：YAMLを手書きしなくても、画面上のボタン・スライダーから「A4縦 / A4横」「ゴシック体 / 明朝体」「余白（15mm / 20mm / 25mm）」「文字サイズ」「基本行間」をワンクリックで切り替え可能（フロントマターと双方向同期）
  - **検索・置換バー（`Ctrl+F` / `Ctrl+H`）**：一致件数のリアルタイム表示、前後ジャンプ、個別置換・一括置換に対応
  - **Undo / Redo（`Ctrl+Z` / `Ctrl+Y`）**：テキスト編集だけでなく、ボタンからの書式挿入や一括置換、ページ設定変更もすべて元に戻す・やり直し可能
  - **ローカル画像の挿入＆ドラッグ＆ドロップ対応**：`.md` ファイルのドロップ読み込みに加え、画像ファイル（PNG / JPEG / GIF / SVG / WebP）をウィンドウにドロップまたは「🖼 画像...」ボタンから選択するだけでカーソル位置に挿入し、PDFとHTML（Base64埋め込み）の両方に反映
  - **未保存変更の保護ダイアログ**：未保存の変更（`*`）がある状態でウィンドウを閉じたり別ファイルを開こうとした際に確認モーダルを表示し、データ消失を防止
  - **業務文書テンプレート挿入（「📋 テンプレート」）**：議事録・障害/インシデント報告書・稟議書・日報の定型フォーマットをワンクリックでカーソル位置に挿入
  - **生Typstコード直接記述（上級者向け、「🧩 Typstコード」/ ` ```typst ` フェンス）**：独自拡張構文では表現できない組版をTypst構文で直接記述可能。PDF出力時はそのまま評価され、HTML出力時は注記付きでソースを表示
  - **見出しアウトラインパネル（「🗂 アウトライン」）**：文書内の見出し一覧をツリー表示し、クリックで該当箇所へジャンプ
  - **最近使ったファイル（「🕒 最近使ったファイル」）**：直近8件のファイル履歴から素早く再オープン（履歴はPC再起動後も保持）
  - **自動保存**：編集を30秒以上放置すると自動でバックアップファイル（`*.autosave.md`）を書き出し、不意の終了に備える
  - **カラーパレット拡張**：既定の赤/青/緑に加え橙・紫ボタン、および任意のHEXカラーコード入力欄に対応
  - **文書全体のアクセントカラー設定**：ページ設定バーから見出し罫線・表ヘッダ・リンク色などに反映されるアクセントカラーを選択可能（フロントマターの `accent-color` と双方向同期）
  - **ブロック単位の文字色・表ヘッダー背景色・表示幅指定**：`{color: ...}` で見出し・段落の文字色を個別に、`{header-bg: ...}` で表のヘッダー行の背景色を個別に、`{block-width: ...}` で段落・見出し等の表示幅（HTML/CSSのwidth相当）を上書き可能
  - **エクスポート後に開くボタン**：PDF/HTML出力成功後、ステータスバーの「📂 開く」から既定アプリで直接確認
  - **下線（「U 下線」）**：`[テキスト]{underline}` で選択範囲に下線を付与。取り消し線（`~~テキスト~~`）も標準Markdown記法でそのまま利用可能
  - **画像サイズ指定**：`![alt](path){width: 50%}` のように画像直後にサイズを添えると、既定の80%幅から個別に変更可能
  - **明示的な空白行（「↕ 空白行」/ `:::space 1em`）**：段落間に任意の高さの垂直スペースを挿入
  - **囲み枠ボックス（「🔲 囲み枠」/ `{box}` + 引用`>`）**：引用ブロックを左バーではなく全周罫線のボックス表示に切り替え、注意事項などを目立たせられる
- **PDF出力 ＆ 単一HTML出力の両対応**
  - 提出・印刷用の **PDF出力（`Ctrl+P`）** と、ページ境界に依存せずブラウザで連続閲覧できる **単一HTML出力（CSS・ローカル画像Base64内包）** の両方に対応

## ショートカットキー一覧

| ショートカット | 動作 |
| :--- | :--- |
| `Ctrl + N` | 新規文書作成 |
| `Ctrl + O` | ファイルを開く（または `.md` ファイルをウィンドウへドロップ） |
| `Ctrl + S` | 上書き保存 |
| `Ctrl + Shift + S` | 名前を付けて保存 |
| `Ctrl + P` | PDF出力 |
| `Ctrl + Z` / `Ctrl + Y` | 元に戻す (Undo) / やり直し (Redo) |
| `Ctrl + F` / `Ctrl + H` | 検索・置換バーの表示切り替え |
| `Ctrl + B` / `Ctrl + I` | 選択範囲を太字 (`**...**`) / 斜体 (`*...*`) で囲む |
| `Ctrl + マウスホイール` | プレビュー表示倍率の拡大・縮小 |

## 独自拡張マークアップ記法

### 1. 文書全体設定（先頭フロントマター / GUI設定バーと連動）
```yaml
---
paper: A4
orientation: portrait   # portrait (縦) / landscape (横)
margin: 20mm
font-size: 10.5pt
line-height: 1.5
font: gothic            # gothic (ゴシック) / mincho (明朝)
accent-color: "#1a73e8" # 見出し罫線・表ヘッダ・リンク色などに反映
---
```

### 2. 表の列幅指定
標準Markdownの表の直前に `{widths: ...}` を1行添えるだけで、列幅比率や固定幅を指定できます。
```markdown
{widths: 22%, 48%, 30%}
| 項目 | 内容・対応状況 | 備考・担当 |
| :--- | :--- | :--- |
| **発生日時** | 2026年10月14日 10:15 〜 10:48 | 監視アラートにて検知 |
| **直接原因** | バックアップジョブの重複によるディスクI/O飽和 | [設定ミス]{red}による重複 |
```

### 3. 段落・見出しの配置と行間制御
```markdown
{align: right}
2026年10月16日  
情報システム部 業務改善推進チーム

{align: center, size: 16pt}
**社内システム障害対応および再発防止策報告書**

{line-height: 1.2, size: 9.5pt}
※この段落だけ行間と文字サイズを少しコンパクトに詰めて表示します。
```

### 4. インライン文字装飾（文字色・文字サイズ・下線・取り消し線）
表のセル内でもパイプ `|` と衝突しない `[テキスト]{属性}` 記法と、従来型の `{color:red|テキスト}` 記法の両方に対応しています。
- `[重要事項]{red}` / `[補足]{blue}` / `[正常]{green}` / `[注意]{orange}` / `[参考]{purple}`
- `[カスタム装飾]{color: red, size: 12pt}`
- `{color:red|重要事項}`
- `[下線テキスト]{underline}`（下線）
- `~~取り消し線~~`（標準Markdown記法）

### 5. ブロック単位の文字色・表ヘッダー背景色
見出し・段落の直前に `{color: ...}` を置くとブロック全体の文字色を、表の直前に `{header-bg: ...}` を置くとヘッダー行の背景色を個別に上書きできます（`{widths: ...}` などと同様、複数行の属性指定は自動的にマージされます）。
```markdown
{color: red}
## このセクションだけ見出し文字を赤くする

{widths: 25%, 75%}
{header-bg: #fdf0e6}
| 項目 | 内容 |
| :--- | :--- |
| 例 | ヘッダー背景だけオレンジ系に変更 |
```

### 6. 画像サイズ指定・明示的な空白・囲み枠ボックス
```markdown
![会議の様子](photo.png){width: 50%}

:::space 1em

{box}
> 注意: この手順は本番環境では実行しないでください。
```

### 7. 上級者向け：生Typstコードの直接記述
独自拡張構文では表現できない組版が必要な場合、` ```typst ` フェンスコードブロックで生のTypstコードを直接記述できます。PDF出力時はそのまま評価され、HTML出力時は評価できないため注記付きでソースを表示します。
```markdown
```typst
#line(length: 50%, stroke: 1pt)
```
```

### 8. 任意改ページ
```markdown
:::pagebreak
```

## アーキテクチャ・ディレクトリ構成

将来的なUIフレームワークの比較検証（`egui` ⇄ `Slint`）や独自構文の拡張が容易に行えるよう、4層の疎結合なモジュール構成をとっています。

```text
Typer/
├── Cargo.toml
├── docs/
│   ├── requirements.md   # 要件定義書 (v0.2)
│   └── roadmap.md        # 開発ロードマップ・マイルストーン
└── src/
    ├── main.rs           # エントリポイント
    ├── model.rs          # 内部文書モデル (AST / 拡張属性の器を持つ中間表現)
    ├── parser.rs         # 標準Markdown + 独自拡張構文パーサー・フロントマター同期
    ├── typst_gen.rs      # 内部文書モデル ➔ Typstコード変換器・ローカル画像解決
    ├── typst_engine.rs   # インメモリTypst組版・共有フォントキャッシュ・PDF出力エンジン
    ├── html_export.rs    # 内部文書モデル ➔ 単一HTML+CSS (画像Base64内包) 出力器
    ├── ui.rs             # egui 2ペインデスクトップUI・検索置換・Undo/Redo・未保存保護
    └── sample.rs         # 起動時サンプル業務報告書原稿
```

## ビルドと実行方法

### 必要環境
- Windows 10 / 11
- Rust ツールチェーン (`rustup` / `cargo`)

### 開発実行・テスト
```powershell
# 単体・結合テストの実行
cargo test

# デスクトップアプリの起動
cargo run
```

### リリースビルド（配布用単一 `.exe` の生成）
```powershell
cargo build --release
```
生成された `target\release\typer.exe` を単体で配布・実行できます。
